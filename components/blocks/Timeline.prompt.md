Этапы внедрения. Номера и сроки — шрифтом цифр.

```jsx
<Timeline steps={[
  { title: 'Разбор задачи', duration: '3–5 дней', body: 'Смотрим процесс, считаем, где теряется время.' },
  { title: 'Прототип', duration: '2 недели', body: 'Собираем работающий кусок и проверяем на живых данных.' },
  { title: 'Внедрение', duration: '4–6 недель', body: 'Доводим до прода и передаём команде.' },
]} />
```

`orientation="horizontal"` — для слайда; больше пяти шагов в строку не ставьте.
