# SiteFooter

Подвал — чёрная секция (`--surface-footer`) с отступом сверху 96px. Три колонки: марка с крупной фразой, разделы, контакты. Надзаголовки колонок — 12px капсом с трекингом 0.2em, цвет `violet-500`. Контакты набраны 20px/500 белым: это не мелкий служебный текст, а способ связи.

Фраза под маркой залита градиентом текста `gray-100 → gray-500`. Это единственное место в системе, где градиент применяется к тексту.

Нижняя строка (копирайт и ссылка на политику) — 12px капсом на `--text-on-inverse-faint`. Не ставьте туда `--gray-600`: на чёрном это 4.34:1 и не проходит AA. Правка внесена по аудиту контраста.

Ссылки разделов ведут на настоящие страницы; не превращайте подвал в карту сайта из несуществующих пунктов.
