# SiteHeader

Шапка сайта. Фиксированная, высота 80px (`--header-height`), фон `rgba(255,255,255,0.8)` с `backdrop-blur(12px)`, в тёмной теме `rgba(17,24,39,0.8)`; снизу — линия `--border-subtle`.

Марка набрана типом (`СИНГУЛЯРНОСТЬ`, 20px/700, трекинг −0.025em) с подписью 10px капсом под ней. Файла логотипа в системе нет — знак не рисуем.

Меню — капс с трекингом 0.05em, цвет `--text-muted`, на hover уходит в `--text-primary` (переход даёт браузер по ссылке; отдельного состояния в проде нет). Справа — переключатель языка (рамка `--border-default`, радиус 6px), переключатель темы `IconButton` и primary-кнопка с иконкой `zap`.

Ниже 860px всё, кроме марки, сворачивается в три тап-таргета 44×44 и полноэкранное меню на `--surface-page`.

Не добавляйте в шапку второй CTA и не меняйте регистр пунктов: капс в меню — одна из трёх разрешённых ролей КАПСа в системе.
