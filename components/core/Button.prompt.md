Кнопка-действие. Текст всегда по формуле «действие + что получит» (positioning §7): «Получить разбор задачи», не «Отправить заявку».

```jsx
<Button variant="accent" icon="arrow-right" href="/contact">Получить разбор задачи</Button>
```

Варианты: primary (шапка), onAccent (внутри hero), accent (финальный CTA), quiet (текстовая ссылка «Смотреть все проекты»).
