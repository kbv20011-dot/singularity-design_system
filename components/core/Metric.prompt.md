Цифра-доказательство. Три формы: пара «было → стало», диапазон, одиночное число. Атрибуция обязательна — без неё цифра выглядит как чужой результат, присвоенный себе.

```jsx
<Metric before="3 дня" after="4 часа" label="сбор отчёта по продажам" attribution="delivered" />
<Metric range="+15–25%" label="конверсии" attribution="concept" />
```

Запрещено: «Мы разработали. Результат: +25%», если проект не наш. Тогда attribution="concept" и формулировка «по опыту команды».
