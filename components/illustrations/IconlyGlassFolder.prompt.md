Иллюстративная стеклянная иконка «Folder» из набора Iconly Glass. Роль: крупный акцент раздела или hero — документы, хранилища, база знаний. НЕ интерфейсная иконка: для интерфейса только `Icon` (lucide).

```jsx
<IconlyGlassFolder style={{ color: 'var(--accent)' }} />
```

Родной размер из Figma (около 103×103), цвет из `currentColor`.
