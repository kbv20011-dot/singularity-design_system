Иллюстративная стеклянная иконка «Bag» из набора Iconly Glass. Роль: крупный акцент раздела или hero — товар, заказ, витрина решений. НЕ интерфейсная иконка: для интерфейса только `Icon` (lucide).

```jsx
<IconlyGlassBag style={{ color: 'var(--accent)' }} />
```

Родной размер из Figma (около 103×103), цвет из `currentColor`.
