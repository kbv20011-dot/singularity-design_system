Иллюстративная стеклянная иконка «Camera» из набора Iconly Glass. Роль: крупный акцент раздела или hero — медиа, видеомонтаж, распознавание по фото. НЕ интерфейсная иконка: для интерфейса только `Icon` (lucide).

```jsx
<IconlyGlassCamera style={{ color: 'var(--accent)' }} />
```
