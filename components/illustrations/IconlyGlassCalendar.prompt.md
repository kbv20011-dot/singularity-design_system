Иллюстративная стеклянная иконка «Calendar» из набора Iconly Glass. Роль: крупный акцент раздела или hero — сроки, этапы, расписание. НЕ интерфейсная иконка: для интерфейса только `Icon` (lucide).

```jsx
<IconlyGlassCalendar style={{ color: 'var(--accent)' }} />
```

Родной размер из Figma (около 103×103), цвет из `currentColor`.
