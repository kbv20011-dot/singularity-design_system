Иллюстративная стеклянная иконка «Info» из набора Iconly Glass. Роль: крупный акцент раздела или hero — пояснение, честный отказ, оговорка. НЕ интерфейсная иконка: для интерфейса только `Icon` (lucide).

```jsx
<IconlyGlassInfo style={{ color: 'var(--accent)' }} />
```

Родной размер из Figma (около 103×103), цвет из `currentColor`.
