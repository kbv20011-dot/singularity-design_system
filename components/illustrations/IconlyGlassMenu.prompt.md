Иллюстративная стеклянная иконка «Menu» из набора Iconly Glass. Роль: крупный акцент раздела или hero — разделы, структура, навигация. НЕ интерфейсная иконка: для интерфейса только `Icon` (lucide).

```jsx
<IconlyGlassMenu style={{ color: 'var(--accent)' }} />
```

Родной размер из Figma (около 103×103), цвет из `currentColor`.
