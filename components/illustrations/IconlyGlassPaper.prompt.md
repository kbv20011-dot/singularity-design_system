Иллюстративная стеклянная иконка «Paper» из набора Iconly Glass. Роль: крупный акцент раздела или hero — первичные документы, договоры, отчёты. НЕ интерфейсная иконка: для интерфейса только `Icon` (lucide).

```jsx
<IconlyGlassPaper style={{ color: 'var(--accent)' }} />
```

Родной размер из Figma (около 103×103), цвет из `currentColor`.
