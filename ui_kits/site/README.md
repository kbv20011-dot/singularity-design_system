# UI-кит: сайт singularity-ai.ru

Воссоздание экранов прода из кода репозитория `kbv20011-dot/singular` (ветка `master`). Не новый дизайн — копия существующего.

## Что собрано

| Экран | Файлы кита | Источник в репозитории |
|---|---|---|
| Главная | `index.html`, `home-screen.jsx`, `site-header.jsx`, `site-footer.jsx` | `pages/HomePage.tsx`, `components/Layout.tsx`, `data/cases.ts`, `data/contacts.ts`, `data/team.ts` |
| Контакты | `contact-screen.jsx` | `pages/ContactForm.tsx`, `data/contacts.ts` |
| Страница сотрудника | `employee-screen.jsx` | `pages/EmployeePage.tsx`, `data/team.ts` |

Навигация по хешу: `#contact` — форма, `#team/bogdan` · `#team/maxim` · `#team/savely` — сотрудники, остальное — главная. Карточки команды на главной ведут на страницу сотрудника.

Порядок блоков главной — воронка из `docs/positioning-v1.md` §10: hero → цифры → кто наш клиент → три двери → во что мы верим → кейсы → диагностика → сравнение и опоры → кому мы не нужны → команда → FAQ → финальный CTA.

## Что можно потрогать

Переключение темы (класс `.dark` на `<html>`), переключатель RU/EN в шапке, бургер-меню на узком экране, аккордеон FAQ, баннер cookie, hover-состояния карточек и кнопок, кольцо фокуса с клавиатуры, нажатие со сжатием, появление блоков при прокрутке, досчёт цифр. Форма контактов работает: валидация имени, Telegram/телефона и согласия, состояние отправки и экран благодарности (отправка имитируется — в проде это Google Sheets).

## Отличия от прода

- Метрики главной показаны компонентом `Metric` с атрибуцией статуса — в проде там просто `AnimatedNumber`. Это принятое решение пользователя (`positioning` §7–§8), а не расхождение по невнимательности.
- Параллакс декоративных фигур hero не воспроизведён: в проде он на `framer-motion useScroll`. Плавание фигур на месте.
- Переключатель RU/EN меняет только состояние — второй языковой набор в кит не переносился.
- Знак бренда в шапке и подвале набран типом: файла логотипа в источниках нет.
